# Roll Master

Link has become a master of somersaults!

This mod improves Link's rolling by removing the brief pause between rolls, allowing for fluid, continuous movement. It also comes with many additional features that are totally configurable.

# Configurable Features:
- **Bunny Hood Roll:** Roll even faster (includes Better Bunny Hood support)
- **Roll Turning:** Change direction during a roll
- **Roll Input Buffer:** Roll with more fluidity
- **Quiet Link:** Silence Link's shouting
- **No Interruptions:** Don't stop to talk if you're rolling
- **Dust Particles:** Leave a visual dust trail
